# RobloxCloseFix
RobloxCloseFix v0.1 Beta — Made by Armenia201o90/ShrillBrake4899/ark201o90/Arkr32. Unofficial Windows tool that closes leftover Roblox processes after the game window closes. Test first; stop using it if Roblox closes during play. Installs a startup entry and scheduled task. Not affiliated with Roblox.
